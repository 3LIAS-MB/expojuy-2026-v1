## 🎯 Motivo del Proyecto

La **ExpoJuy** es el evento ferial e industrial más trascendente del Noroeste Argentino (NOA), con una trayectoria histórica que congrega a los sectores minero, energético, agroindustrial, tecnológico, turístico y cultural de la región. 

Para su **17ª Edición (2026)**, el desafío principal radicaba en **modernizar por completo su ecosistema digital**:
- **Superar la experiencia ferial estática:** Crear un portal web inmersivo, reactivo y de estándar internacional que proyecte a Jujuy como el epicentro del **Corredor Bioceánico de Capricornio**.
- **Dinámica Dual (B2B + Comunidad):** Comunicar con claridad la convivencia de mañanas exclusivas de negocios internacionales y tardes/noches culturales y familiares.
- **Sustentabilidad y Cero Papel:** Desmaterializar las entradas físicas mediante un sistema de acreditación y credenciales 100% digitales con códigos QR accesibles sin conexión.
- **Atención Continua con Inteligencia Artificial:** Brindar al visitante y expositor un asistente virtual interactivo ("Llamita IA") capaz de resolver consultas sobre agenda, stands, accesos y actividades en tiempo real.

---

## 🚀 Objetivos Estratégicos

1. **Visibilidad Global:** Posicionar la matriz productiva jujeña (Litio, Cauchari Solar, Bioenergía, Vinos de Altura y Startups) ante delegaciones e inversores de Brasil, Chile, Paraguay, Bolivia y el mundo.
2. **Experiencia de Usuario de Vanguardia (UI/UX):** Implementar animaciones cinemáticas con GSAP, ensambles tridimensionales de marca y estética editorial sobria de alta legibilidad.
3. **Optimización Multiplataforma:** Diseñar layouts ultra-responsivos garantizando desempeño y ergonomía visual perfecta tanto en monitores de escritorio como en dispositivos móviles modernos (desde 360px hasta 440×956 y pantallas ultrawide).
4. **Agilidad Operativa:** Reducir fricciones de acreditación para expositores, prensa y público general con pases QR de validación en menos de 3 segundos.
5. **Transparencia e Información en Vivo:** Publicar novedades feriales, cronogramas de conferencias y mapa interactivo del predio en Ciudad Cultural.

## 🛠️ Stack Tecnológico

### Core & Framework
- **[Next.js 16 (App Router)](https://nextjs.org/):** Framework de React con Server Components, optimización de fuentes e imágenes y enrutamiento híbrido.
- **[React 19](https://react.dev/):** Biblioteca base para la construcción de interfaces de usuario concurrentes y reactivas.
- **[TypeScript 5](https://www.typescriptlang.org/):** Tipado estático riguroso en todo el ciclo de vida del frontend y servicios de datos.

### Estilos & Animación
- **[Tailwind CSS v4](https://tailwindcss.com/):** Motor de diseño de última generación con alto rendimiento y utilidades modernas.
- **[GSAP 3 (GreenSock)](https://greensock.com/gsap/):** Suite profesional de animación para scroll triggers, pinning, trayectorias SVG Bézier y transiciones 3D.
- **[tw-animate-css](https://www.npmjs.com/package/tw-animate-css):** Microanimaciones de entrada y transiciones de estados modales.

### Inteligencia Artificial & Servicios
- **[Google Gemini API](https://ai.google.dev/):** Modelo de lenguaje generativo para el asistente virtual institucional Llamita.
- **[Radix UI](https://www.radix-ui.com/):** Componentes primitivos accesibles y sin estilos para modales, diálogos y slots.
- **[React Icons](https://react-icons.github.io/react-icons/):** Iconografía vectorial completa de FontAwesome 6 y Lucide.
- **[Leaflet](https://leafletjs.com/):** Cartografía interactiva para el plano del predio ferial.

## 📥 Guía de Instalación y Ejecución

Sigue estos pasos para clonar y ejecutar el proyecto localmente en tu entorno de desarrollo:

### 1. Prerrequisitos
Asegúrate de tener instalados en tu sistema:
- **Node.js**: Versión `18.18.0` o superior (recomendado `20.x` LTS o `22.x`).
- **npm** (incluido con Node.js), **pnpm** o **bun**.
- **Git** instalado.

### 2. Clonar el Repositorio
```bash
git clone https://github.com/3LIAS-MB/expojuy-2026-v1.git
cd expojuy-2026-v1
```

### 3. Instalar Dependencias
Instala los paquetes necesarios del proyecto:
```bash
npm install
```

### 4. Configurar Variables de Entorno
Crea un archivo `.env.local` en la raíz del proyecto basado en la siguiente sección:
```bash
cp .env.example .env.local
```
*(o crea manualmente el archivo `.env.local` y añade tu clave de API de Gemini)*.

### 5. Iniciar Servidor de Desarrollo
```bash
npm run dev
```
Abre tu navegador en [http://localhost:3000](http://localhost:3000) para explorar la plataforma en vivo.

### 6. Compilación para Producción
Para validar la compilación y generar el paquete optimizado de producción:
```bash
# Comprobar tipado estático
npx tsc --noEmit

# Compilar el bundle de producción
npm run build

# Iniciar el servidor productivo
npm run start
```

## 🔐 Configuración de Entorno

El proyecto requiere la clave de API de Google Gemini para habilitar el motor conversacional de **Llamita**:

Crea un archivo `.env.local` en la raíz del directorio con el siguiente contenido:

```env
# Google Gemini API Key para el Asistente Virtual Llamita (ExpoJuy 2026)
GEMINI_API_KEY=tu_clave_de_api_aqui
```

> 💡 **¿Cómo obtener una clave gratuita?**  
> Ingresa a [Google AI Studio](https://aistudio.google.com/), genera una API Key y pégala en tu archivo `.env.local`.

## 📂 Estructura del Repositorio

```text
WEB_EXPOJUY/
├── public/                     # Recursos estáticos públicos
│   ├── bot/                    # Assets del asistente IA Llamita
│   ├── images/                 # Fotografías, banners, sponsors y cerros
│   │   ├── brand/              # Isologotipos y vectores de identidad
│   │   ├── cerro/              # Capas de profundidad para el efecto parallax
│   │   ├── evento/             # Fotos de conferencias y predio ferial
│   │   └── sectores/           # Litio, Cauchari Solar y agroindustria
│   └── video/                  # Videos de fondo del Hero (videoplayback.webm)
├── src/
│   ├── app/                    # App Router de Next.js
│   │   ├── api/chat/           # Endpoint del backend para Gemini AI
│   │   ├── globals.css         # Tokens de diseño, Tailwind v4 y estilos globales
│   │   ├── layout.tsx          # Layout raíz con metadata SEO
│   │   └── page.tsx            # Landing Page principal de ExpoJuy 2026
│   ├── components/             # Componentes modulares
│   │   ├── chat/               # Widget inteligente flotante (ExpoBotWidget)
│   │   ├── layout/             # Footer, Navbar y menús
│   │   ├── news/               # Sección de noticias, tarjetas y modal de lectura
│   │   ├── prototype/          # Hero, SiteHeader, AboutExperience, Expositores
│   │   ├── social/             # Muro social e integración comunitaria
│   │   ├── ui/                 # Primitivas UI reutilizables (Botones, badges)
│   │   ├── BrandingIntro.tsx   # Animación 3D de entrada cinematográfica
│   │   ├── FaqSection.tsx      # Acordeón de preguntas frecuentes
│   │   └── ContactSection.tsx  # Formulario institucional de contacto
│   └── data/                   # Colecciones de datos (noticias, expositores, faq)
├── .env.local                  # Variables de entorno locales (ignorado en git)
├── package.json                # Dependencias y scripts del proyecto
├── tsconfig.json               # Configuración de compilación TypeScript
└── README.md                   # Documentación principal del proyecto
```
